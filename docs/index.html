Remote-ready DeepSeek Harness

Cloud deployment of dsh with free models (OpenCode Zen + Empero), Exa MCP web search (replaces DeepSeek official search), remote trust for browser settings, Agent Rail, and Telegram.

Web search: DeepSeek off, Exa on

Stock dsh ships web-search-deepseek and searchProvider: deepseek-official. This fork patches web to exa-mcp, disables DeepSeek search at runtime, and registers settings namespace web-search-exa.

DSH_WEB_SEARCH_PROVIDER=exa-mcp
DSH_WEB_FETCH_PROVIDER=exa-mcp
